# 공통 디자인 기준(모든 장르)

## 기본 설정

- `pres.layout = 'LAYOUT_WIDE'`(13.333 × 7.5in)를 슬라이드 추가 전에 명시한다. 언어는 한국어로 한다.
- 폰트는 전부 **맑은고딕(Malgun Gothic)**으로 고정한다. Calibri, Cambria, Pretendard, Inter, 모노스페이스는 금지한다.
  - 글자마다 `fontFace: 'Malgun Gothic'`을 지정한다. 표 셀과 한 글상자 안의 부분 서식도 빠뜨리지 않는다.
  - 테마 글꼴도 맑은고딕으로 바꾼다: `pres.theme = { headFontFace: 'Malgun Gothic', bodyFontFace: 'Malgun Gothic' }`. 기본 테마는 Calibri라서, 바꾸지 않으면 받은 사람이 PowerPoint에서 새 글상자를 추가할 때 Calibri가 들어간다. `mgc_report.js` · `slim.js`는 이미 적용돼 있고, 안내문형처럼 직접 작성하는 덱은 이 줄을 넣는다.
- 검사: `python3 check_text.py out.pptx`가 테마와 모든 글자의 글꼴을 확인하고, 맑은고딕이 아닌 글자는 위치와 함께 출력한다.
- 모든 텍스트 상자는 margin 0을 쓴다. 표 셀 여백은 [0.05, 0.12, 0.05, 0.12]다.
- 금지 요소: 그라데이션, 반투명 블러, 깜박임, 이모지, 같은 모양 둥근 카드 반복, 크림 · 오프화이트 배경.

## 장르별 여백 · 본문 영역

| 항목 | 안내문형 · 기능 보고형 | 간결 기획서형 |
|---|---|---|
| 좌우 여백 | 0.5in | 0.6in |
| 본문 폭 | 12.33in(오른쪽 끝 12.83) | 12.13in(오른쪽 끝 12.73) |
| 본문 시작 | y 1.95 | y 1.95 |
| 본문 하단 | 6.85in 안에서 끝냄 | 6.85in 안에서 끝냄. 예외: 핵심 한 줄 · 화면 캡션 줄은 6.9까지 |
| 하단 정보줄 | y 6.95(진행 현황 · 쪽 번호) | 쪽 번호만 y 7.0 |

- 간결 기획서형 예외 값은 `kit.js` 검사 기준(표 6.85, 핵심 한 줄 6.9)과 같다.

## 깔끔한 장표

- **장식 도형은 넣지 않는다.** 화면 밖까지 이어지는 큰 원, 반원, 띠, 사선, 배경 무늬, 장식용 아이콘이 모두 해당한다. 표지도 예외가 아니다.
- **슬라이드 밖으로 나가거나 걸치는 요소는 하나도 두지 않는다.** 모든 도형과 이미지는 0 ≤ x, y이고 x + w ≤ 13.333, y + h ≤ 7.5 안에 있어야 한다.
- 도형 하나하나에 대해 "이 도형이 무슨 정보를 전달하는가"를 한 줄로 설명할 수 있어야 한다. 설명할 수 없으면 뺀다.
- **허용하는 도형은 정보를 담는 것뿐이다.**

| 장르 | 허용 도형 |
|---|---|
| 공통 | 내용 박스 · 카드(텍스트가 들어감), 표, 화면 이미지와 그 테두리, 화살표 글자 "→" |
| 기능 보고형 | 흐름 헤더 단계, 장 구분 칩, 순번 원(지름 0.4in, 숫자가 들어감) |
| 간결 기획서형 | 핵심 한 줄의 세로선, 간지 구분선, 화면 구조 장의 영역 테두리와 번호 원(지름 0.24in) |
| 간결 기획서형 흐름도 | 시작 · 끝 둥근 상자, 처리 상자, 판단 마름모, 안내 상자, 직교 연결선(끝 화살표), 분기 이름 글자, 장 오른쪽 위 범례(모양 4종 + 이름). 모두 `flow_parts.js`로만 그린다 |
| 연동 문서 | 아키텍처 도식의 순서 번호 원(지름 0.26in), 처리 구조 도식 상자 · 화살표(`pptx_edit.py`의 `box` · `arrow`) |

- 표지는 단색 배경(doc-bg-800)에 글자 4줄(문서 종류, 제목, 부제, 날짜 · 부서)만 둔다. 기능 보고형 · 안내문형은 `addCover()`(`mgc_report.js`), 간결 기획서형은 `cover()`(`slim.js`, 같은 모양)를 쓴다.
