# 안내문형(가맹점 · 파트너 안내, 정책 공지)

공통 기준은 `references/design-common.md` · `references/writing.md` · `references/text-fit.md`를 따른다.

## 장 순서

8장 내러티브 순서를 유지한다(생략 가능).

1. 표지: `addCover()`로 만들고 단색 배경에 글자만 둔다. 부제나 날짜 줄에 문서 목적 · 배포 대상을 적는다.
2. 한 장 요약("아셔야 할 N가지")
3. 작동 방식(번호 스텝)
4. 기준 · 조건표
5. 추가 기준표
6. 체크리스트
7. FAQ
8. 마무리 요약 + 문의처(brand-yellow 바탕 + brand-black 글씨 CTA 버튼)

## 배경 · 크기

- 배경은 다크(doc-bg-800/900)와 라이트(white)를 번갈아 배치한다.
- 직접 작성하는 덱이므로 테마 글꼴 교체 줄을 넣고(`references/design-common.md` 「기본 설정」), 모든 글상자를 `fit()`에 통과시킨다.

| 요소 | 크기(pt) |
|---|---|
| 표지 타이틀 | 36~40 |
| 스텝 숫자 | 27~38 |
| 섹션 헤더 | 19~20 |
| 소제목 | 15~16 |
| 본문 | 11~13 |
