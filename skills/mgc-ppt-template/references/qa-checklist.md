# 검수

모든 작업의 마지막에 수행한다. 체크 항목은 규칙을 다시 쓰지 않고 확인만 한다. 규칙 본문은 각 항목의 기준 위치에 있다.

## 1. 자동 검사(모든 덱: 손으로 고친 파일 · QA 수정 요청 덱 포함)

| 순서 | 명령 | 통과 기준 |
|---|---|---|
| 1 | `python3 /mnt/skills/public/pptx/scripts/office/validate.py out.pptx` | 통과(사용자 판 원본의 `revisionInfo` 경고는 그대로 둠) |
| 2 | `python3 check_text.py out.pptx` | '글꼴·줄바꿈 통과', [기호] 0건 |
| 3 | `python3 check_clean.py out.pptx` | '깨끗함' |
| 4 | `python3 compare_layout.py 기준.pptx out.pptx`(기준 덱이 있을 때) | 패턴과 행 수가 같으면 불일치 0. 단계 수가 기준 덱(3단계)과 다르면 흐름 헤더 도형은 불일치로 나오는 것이 정상 |
| 5 | `soffice.py --headless --convert-to pdf` → `pdftoppm -jpeg -r 80` | 전 장을 눈으로 확인(아래 항목) |

- 2번에서 문제가 나오면 `references/text-fit.md` 「넘칠 때 고치는 순서」대로 고치고 다시 생성 · 검사한다.
- 2번의 [참고] 줄 끝 「·」는 문장 속 긴 나열인지 눈으로 확인한다.

## 2. 공통 체크리스트(모든 덱)

- [ ] 글꼴이 전부 맑은고딕이고, 줄 탈락 · 줄 수 초과 · 한 줄에 두 문장이 없는가(`references/text-fit.md`)
- [ ] 장식 도형이 없고, 슬라이드 밖으로 나가거나 걸친 요소가 없는가(`references/design-common.md` 「깔끔한 장표」)
- [ ] 본문이 하단 기준 안에서 끝나고 하단 정보줄 · 쪽 번호와 겹치지 않는가(`references/design-common.md` 「장르별 여백 · 본문 영역」)
- [ ] 제목이 「토픽: 서술」 한 줄이고, 표 칸 · 설명 · 각주는 개조식, 핵심 문장은 서술형인가(`references/writing.md` 「문체」)
- [ ] 글머리가 「- 」(설명 열은 1개여도)이고 「•」 · 「 — 」 구분이 없는가, 빈 칸 「—」이 가운데인가(`references/writing.md` 「기호」)
- [ ] 토큰 밖 색이 없는가(이전 값 회색 7A6A5E · 이전 빨강은 `fix_colors`로 정리), 빨강이 모두 FF0000이고 최종 정책 문구에만 장당 3곳 이하인가(`references/writing.md` 「강조」)
- [ ] 예시값 "(예시)", 기준점, 명칭 통일('MY매장', 손님/회원, CJ ONS · OnePG)을 지켰는가(`references/writing.md`)
- [ ] 화면 캡처에 잡티가 없고 alt에 파일 경로가 없는가
- [ ] 렌더에서 제목이 한 줄이고, 고유 명칭 · 단어가 줄 경계에서 잘리지 않았는가

## 3. 장르별 추가 항목

### 기능 보고형

- [ ] 흐름 헤더가 시점 순서이고 현재 단계만 활성인가
- [ ] 장 구분 칩, 첫 장 진행 현황 · 운영 담당, 모든 장 쪽 번호가 있는가
- [ ] 노랑이 슬라이드당 1곳인가, 순번(다크 브라운)과 화면안 번호(골드)가 분리됐는가

### 간결 기획서형

- [ ] 상단 흐름 헤더 · 장 구분 칩 · 순번 원이 없는가
- [ ] 표지 · 간지 색이 기준 표(검정 배경 · F2F2F2 · D9D9D9 · 595959)와 같은가(`references/design-common.md` 「깔끔한 장표」)
- [ ] 노랑 면(띠 · 칸 배경)이 없는가(「신규 개발」 칸 badge-bg만 허용)
- [ ] 쪽 번호가 PowerPoint 슬라이드 번호(표지 포함)와 같은가
- [ ] 목차 · 간지 · 체크리스트 장 번호가 실제 장 제목과 맞는가(렌더 후 제목 추출로 대조)
- [ ] 화면 구조 장의 번호 · 테두리가 표 번호와 1:1인가, 화면 문구가 프로토타입 원본과 같은가
- [ ] 상태 전이 장의 캡처가 시간 순서이고 표 열과 1:1인가, 상태 캡처가 기본 화면인가
- [ ] 영역별 좌우 끝선(0.6 · 12.73)이 맞고, 범례 · 보조 설명이 12.73을 넘지 않는가, 글자 크기가 검증값 이상인가(`references/genre-slim-spec.md`)
- [ ] 렌더에서 표와 핵심 한 줄, 캡션과 표, 설명 제목 줄바꿈, 화면 구조 장의 단과 표가 겹치지 않는가

### 흐름도 장

- [ ] 논리 검수 9항목을 장마다 한 번씩 확인했는가(`references/flowchart.md` 「논리 검수」)
- [ ] 렌더에서 분기 이름 · 상자 글 · 선이 겹치지 않는가

## 4. 문서 유형별 추가 항목

### 연동 문서(`references/integration-doc.md`)

- [ ] 번호 원본 장이 있고 번호를 쓰는 장마다 출처 줄이 있는가, 본문에 번호만 쓴 곳이 없는가
- [ ] 키가 모두 "키(한글 이름)"인가
- [ ] 쓰지 않는 기능 · API 이름이 0건인가(번호 · 흐름도 이미지 포함)
- [ ] 개발 구분 값이 "신규 개발 / 기존 수정 / 확인 태그" 중 하나인가
- [ ] 줄인 말(번호 · 모듈 · 주체 없는 서버 · PG) 검색 결과가 머리행 외 0건인가

### 사용자 판 수정(`references/edit-user-pptx.md`)

- [ ] 장을 넣고 뺀 뒤 쪽 번호 · 목차 · 간지 · 본문 장 참조가 맞는가
- [ ] 렌더에서 표와 아래 도식이 겹치지 않고, 두 줄로 넘친 제목이 없는가
- [ ] 사용자의 배치 · 색 · 글자 크기를 바꾸지 않았는가

### 최종본(`references/final-deliverable.md`)

- [ ] 버전 문자열이 파일명 · 표지 · 노트 · PRD에서 모두 같은가
- [ ] 이력 표현 검색 0건인가
- [ ] 대칭 규칙이 양방향으로 모든 위치에 적혀 있는가, 장끼리 모순이 없는가
- [ ] 마지막 「확인 필요」 영역에 정해진 항목이 남아 있지 않은가
